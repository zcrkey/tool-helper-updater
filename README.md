# 日常工具助手

日常工具助手是一款桌面效率工具，帮你管理**计划任务**和**定时提醒**，还内置条码生成识别、图片水印、数据库工作台和对象存储工作台等实用工具，让日常工作生活更有条理。数据库与对象存储工作台通过主密码保护，连接凭据只保存在本地。

## 1. 快速开始

### 下载地址

https://github.com/zcrkey/tool-helper-updater/releases

### 安装与启动

下载安装包完成安装后，双击桌面图标启动应用。

应用启动后会在**系统托盘**（屏幕右下角）显示图标。

关闭窗口只是隐藏界面，应用仍在后台运行。需要彻底退出时，有以下两种方式：

- 在主界面左下角点击"退出"按钮

  ![退出按钮](snapshot/app-quit.png)

- 右键托盘图标选择"退出程序"

  ![托盘图标](snapshot/tray-icon.png)

## 8. 通知弹窗

提醒触发时，屏幕右下角会弹出一个通知窗口：

![通知弹窗](snapshot/reminder-notifymode.png)

弹窗的交互方式：

| 操作                   | 效果                                |
| ---------------------- | ----------------------------------- |
| 点击内容区域           | 打开计划 / 提醒详情弹窗查看完整信息 |
| 点击右上角 ✕           | 关闭弹窗                            |
| 什么都不做（短暂提醒） | 约 12 秒后自动消失                  |

提醒触发时，任务栏的应用图标也会闪烁，吸引你注意。

## 11. 常见问题

**问：我关了窗口，但应用还在？**

这是正常设计。关闭窗口只是隐藏界面，应用仍在后台运行。需要彻底退出时，有以下两种方式：

- 在主界面左下角点击"退出"按钮
- 右键托盘图标选择"退出程序"

**问：到时间了提醒没有弹出来？**

请检查：

1. 提醒状态是否为"启用中"
2. 下次触发时间是否正确

**问：数据库 / S3 为什么一直要求输入主密码？**

主密码是进入数据库和 S3 模块的访问闸门。首次使用需要设置，之后每次进入或空闲超时都需要解锁。持续使用应用会自动续期，也可以按 `Ctrl+Alt+L` 立即锁定。

**问：忘记主密码怎么办？**

在锁屏页点击"忘记主密码"按提示重置。重置会删除主密码，并清空数据库 / S3 的连接、凭据和记录；计划、提醒等其他数据不受影响。

**问：隐藏模块后，提醒还会弹吗？**

会。隐藏只影响侧边栏入口，提醒调度、弹窗和已有数据都不会被删除。

**问：我的数据安全吗？**

所有数据存储在本地电脑上，不会自动上传到任何云端。数据库 / S3 的连接凭据通过系统级加密存储，包含完整配置的备份文件使用主密码加密。你可以手动导出备份文件存到安全位置。
